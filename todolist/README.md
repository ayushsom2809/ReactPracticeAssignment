# React Todo List

A simple todo list app built with React and JavaScript.

## Features

- Add new todos
- Mark todos as complete
- Delete todos
- Local state only (no backend)

## Folder Structure

```
public/
  index.html
src/
  components/
    TodoList.js
    TodoItem.js
  pages/
    App.js
  styles/
    main.css
  index.js
```

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Customization

- Edit styles in `src/styles/main.css`
- Add more features in `src/pages/App.js` and `src/components/`
